## 手册确认的接口

- 第 1–5 页：半双工 UART、115200 baud；不是 PWM 舵机。
- 第 4 页：GND、VIN、SIG；控制器与独立舵机电源需要共地。
- 第 5 页参数表：额定 11.1 V，工作 9.6–12.6 V；堵转电流 3.2 A/只。
- 第 5、13–18 页：位置 0–1000 对应 0–240°，500 对应 120°。
- 第 6 页：逐个连接设置不同 ID 后再串联。
- 第 2 页：字节协议另见 Hiwonder Bus Servo Communication Protocol，此 PDF 未包含该文件。

树莓派应通过兼容该舵机的半双工总线接口板连接，不能将 VIN 接至树莓派供电引脚。
若使用 BusLinker，需要确认它暴露的是透明串口还是控制板命令接口。
八只舵机堵转电流简单相加为 25.6 A；这不是日常运行电流或电源选型结论。
